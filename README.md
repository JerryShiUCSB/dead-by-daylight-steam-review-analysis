# Dead by Daylight Steam Review Analysis

A Statistical Process Control (SPC) project analyzing player reviews of Dead by Daylight using R.

## Overview

This project analyzes 30,782 English Steam reviews collected over a 30-week period in 2025 to study changes in negative player feedback.

The analysis applies DMAIC and Six Sigma methods to identify unusual patterns and examine common player complaints.

## Tools and Methods

* R and RStudio
* Statistical Process Control (SPC)
* DMAIC and Six Sigma
* p-Charts
* Pareto Analysis
* Cause-and-Effect Diagrams
* Process Flowchart and Value Stream Mapping

## Key Findings

* The overall negative-review proportion was 24.7%.
* 14 weeks fell outside the three-sigma control limits.
* Gameplay balance and technical issues were major complaint categories.
* Recommendations focused on better complaint collection, patch testing, and ongoing monitoring.
